# Cognitive Action Taxonomy

> Version: 0.2
> Status: Canonical cross-scene cognitive-action vocabulary

## 1. Purpose

This file owns the stable `C1`–`C14` cognitive-action IDs used by exam mapping, Scene evidence design, analytics, and future model coverage work. It does not define stage order or Physics Models.

## 2. Taxonomy

### C1 — Identify Phenomenon
Recognize what physical process is happening.

### C2 — Translate to Physics Language
Convert everyday wording into physical quantities and relationships.

### C3 — Identify Physical Quantities
Identify the quantities/states relevant to the situation.

### C4 — Distinguish Related Concepts
Separate concepts that are easy to confuse.

### C5 — Identify Causal Relationship
Determine what changes what and in what direction.

### C6 — Identify Energy Transfer Mechanism
Determine how energy enters, leaves, transfers, or converts within/between systems.

### C7 — Identify Conditions / Constraints
Determine whether a conclusion or model is justified under the stated conditions.

### C8 — Compare Variables
Reason about controlled variables, ratios, and proportional relationships.

### C9 — Select / Construct Model
Choose or construct the physical model that explains the problem.

### C10 — Apply Model
Use the selected model in the specific context.

### C11 — Qualitative Prediction
Predict what will happen when a relevant condition changes.

### C12 — Quantitative Reasoning
Translate physical relationships into mathematical reasoning/calculation.

### C13 — Check Sufficiency
Determine whether the available information/conditions are sufficient to justify a claim.

### C14 — Transfer
Apply the same deep physical model to a different surface context or representation.

## 3. Usage Rule

Other spec files should reference these IDs rather than redefine their meanings. Model-specific or Scene-specific documents may select a subset and describe concrete evidence for an action. Adding, renaming, or changing the semantics of a `C#` ID requires updating this file first and then auditing all references.
