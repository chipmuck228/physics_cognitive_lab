# Scene 02 Learner Experience Script v1

> Status: **EXPERIMENTAL DESIGN ARTIFACT** — not canonical  
> Scene: `four-stroke-engine`  
> Primary model: `chemical-energy-internal-energy-mechanical-energy`  
> Constrained by: UPLP, Evidence Design, Interaction Runtime/State, Scene 02 specs  
> If this Script conflicts with a canonical contract, the contract wins.

The existing Scene 02 `interaction-script.md` remains Scene sitting. This Script does not delete it.

Core experience (felt, not shown as a workflow):

```text
WATCH A CYCLE → NOTICE DIFFERENT MOTIONS → IDENTIFY WHAT CHANGES
→ PREDICT NEXT STATE → MANIPULATE / ADVANCE CYCLE
→ EXPLAIN ENERGY CHANGE → BUILD ENERGY / CAUSAL MODEL
→ APPLY TO NEW ENGINE-LIKE CONTEXT → EXAM REPRESENTATION
→ INDEPENDENT USE
```

Do **not** turn Scene 02 into “背四个冲程名称。”

The four-stroke cycle is the physical environment. The deeper model is energy transformation and causal structure.

Experience grammar: **temporal / causal / energy relation**. Do not copy Scene 07’s four spatial optical-bench trials, ray-construction MODEL, or optics vocabulary.

## S02-M01 — SEE THE ENGINE MOVE

**Stage:** ENTRY

**Learner enters with**

May know: fuel burns; cars have engines.  
May NOT know: four stroke names; valve behavior; energy transformation sequence.

**Experience intention**

Make the engine a physical system, not a textbook diagram.

**Learner should feel**

“这是一台会动的装置，我可以先看它。”

**Physical world**

Show clearly, where the existing Scene supports it: cylinder, piston, intake/exhaust valves, gas/fuel-air region, crank / mechanical output. Ground vocabulary beside the object.

Examples:

- 活塞: “这个上下运动的部件叫活塞。”
- 气缸: “活塞在这个空间里上下运动。”

Do not explain all four strokes at once.

**System says**

“先看它动一遍。

不用记名字，先看看哪些东西在动、什么时候发生变化。”

**Learner does**

Enters and watches.

**System responds**

The engine is available. No energy lecture.

**Evidence meaning**

Entry only. Not observation evidence. Not energy understanding.

**Do not**

- name and define 吸气 / 压缩 / 做功 / 排气 as the first task
- copy Scene 07 optical-bench copy
- specify React components

## S02-M02 — WHAT ACTUALLY CHANGES?

**Stage:** OBSERVE

**Experience intention**

Learner notices piston direction, valve states, gas entry/exit, combustion/expansion event, mechanical motion.

**Learner should feel**

“我在看变化，不是在对名称。”

**Physical world**

Playback / cycle is dominant. Stroke names are not the observation target.

**System says**

“先别管每一步叫什么。

看一遍以后，你注意到了哪些变化？”

**Learner does**

Observes selected physical features.

**System responds**

What they marked is kept. The engine still shows the cycle.

**Evidence meaning**

Observation of physical features. Must **not** treat stroke-name recall as the primary observation evidence.

**Do not**

- ask for stroke names as the main OBSERVE product
- reveal 化学能 / 内能 / 机械能

## S02-M03 — DESCRIBE ONE MOMENT

**Stage:** DESCRIBE

**Experience intention**

Describe a meaningful engine state with visible referents.

**Learner should feel**

“我在说这个时候发生了什么。”

**Physical world**

Show one (or the existing two) meaningful engine state(s). Visible piston, valves, combustion.

**System says**

“看着这个时候的发动机。

用自己的话说说：
活塞在怎么动？气体发生了什么？”

If valve state is relevant:

“哪边开着，哪边关着？”

**Learner does**

Describes observed physical relations in their own language. Existing structured snapshot gates remain if Scene 02 evidence already requires them.

**System responds**

The description is kept. No “correct stroke name” grade.

**Evidence meaning**

Observed physical relations, not vocabulary recall. Must not require “吸气冲程 / 压缩冲程 / 做功冲程 / 排气冲程” before the learner has built the distinctions.

**Do not**

- make stroke names the description product
- leak evaluator language

## S02-M04 — WHAT HAPPENS NEXT?

**Stage:** PREDICT

**Experience intention**

Freeze at a meaningful moment and ask for a genuine prediction. Prediction is not an exam.

**Learner should feel**

“我先猜接下来会怎样。猜错也可以。”

**Physical world**

The engine is visible, stopped at the prediction’s physical question. Existing Scene 02 prediction is about a condition change (combustion off / piston locked), not “name the next stroke.” This Script must not invent a new experiment.

**System says**

“现在先停在这里。

如果发动机继续运行，
你觉得接下来会发生什么？”

Scene 02’s existing first prediction is a condition intervention, so the visible question should stay physically specific, for example whether main output still happens when combustion does not. The spirit is the same: commit a physical guess before changing the world.

If the learner does not know why, allow: “我现在还说不上来。”

**Learner does**

Predicts a physical change. May or may not have a reason.

**System responds**

The guess is remembered. Experiment becomes available.

**Evidence meaning**

Precommit prediction. Optional reason only when actually provided. “No reason yet” must never be converted into causal-reasoning evidence.

Canonical constraint: Scene 02 `evidence-contract.md` currently requires an authored reason with `hasOwnWords`. This Script must not silently delete that gate. An honest-unknown sentence may satisfy *authored text* without being treated as causal understanding.

**Do not**

- force a fabricated energy explanation
- reveal the experimental result
- copy Scene 07 F/2F prediction wording

## S02-M05 — RUN IT AND SEE

**Stage:** EXPERIMENT

**Experience intention**

Advance / manipulate the cycle using existing deterministic Scene physics, then compare with the guess.

**Learner should feel**

“我在检验刚才的猜想。”

**Physical world**

Existing two high-information experiments remain:

- combustion disabled
- piston / mechanical system locked

Do not clone Scene 07’s four spatial trials.

**System says**

“好，现在让它继续运行。

看看和你刚才猜的一样不一样。”

Then, after the result:

“刚才真正推动活塞发生明显运动的是哪一段？”

Do not immediately provide “做功冲程” as the answer if discovering that relation is part of the task.

**Learner does**

Runs the condition change, records what happened, compares, reflects in own words.

**System responds**

Deterministic physics result. No LLM correctness.

**Evidence meaning**

Existing five-part experiment closure. Must not be interpreted as energy-chain mastery.

**Do not**

- let clicking autoplay close the experiment
- give the energy slogan as the experimental “answer”

## S02-M06 — WHERE DID THE ENERGY COME FROM?

**Stage:** EXPLAIN

**Experience intention**

This is a critical Scene 02 moment. After combustion / expansion / piston movement, ask where the energy came from.

**Learner should feel**

“活塞不是自己随便动的。能量有来处。”

**Physical world**

Two experimental records remain visible as referents.

**System says**

“刚才活塞自己动起来了吗？

让它发生明显运动的能量从哪里来？”

Allow reasoning from the visible process, then move toward:

```text
fuel / combustion
→ hotter / higher-energy gas
→ expansion
→ piston motion
```

**Learner does**

Explains the causal energy path in their own words. Existing EXPLAIN structure remains authoritative.

**System responds**

Scaffold within existing EXPLAIN AI policy. LLM must not decide physical correctness.

**Evidence meaning**

Existing EXPLAIN evidence. The relation matters. A memorized phrase “化学能转化为内能再转化为机械能” must not be the only acceptable expression if the existing evaluator already accepts equivalent relations.

**Do not**

- let LLM grade physics
- require the textbook phrase as the only wording
- copy Scene 07 meeting-language EXPLAIN

## S02-M07 — THE FOUR PARTS HAVE DIFFERENT JOBS

**Stage:** MODEL

**Experience intention**

Stop seeing four disconnected animations. Construct causal/energy structure. Names attach after meaning:

```text
physical process → meaning → name
```

not name → memorize definition.

**Learner should feel**

“四段动作不同，但它们一起完成一件事。”

**Physical world / model workspace**

Existing energy-chain MODEL UI remains model-owned. Expose:

```text
fuel / chemical energy
        ↓
combustion / internal-energy increase
        ↓
gas expansion
        ↓
piston / mechanical motion
```

and how the other strokes prepare/reset the cycle.

**System says** (conceptually)

“现在把一整轮放在一起看。

这四段虽然动作不同，
但它们一起完成了一件什么事？”

The names 吸气 / 压缩 / 做功 / 排气 may now be attached to already-understood processes.

**Learner does**

Constructs the energy / causal chain using the existing MODEL representation.

**System responds**

Existing MODEL evaluator. Presentation must not infer acceptance.

**Evidence meaning**

Correctly ordering four stroke names is **not** model construction. Energy/causal structure is.

**Do not**

- copy Scene 07 ray-construction UI
- treat four-name order as L4
