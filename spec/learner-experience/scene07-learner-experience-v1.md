# Scene 07 Learner Experience Script v1

> Status: **EXPERIMENTAL DESIGN ARTIFACT** — not canonical  
> Scene: `convex-lens-optical-bench`  
> Primary model: `convex-lens-imaging`  
> Constrained by: UPLP, Evidence Design, PRI, Interaction Runtime/State, Scene 07 specs  
> If this Script conflicts with a canonical contract, the contract wins.

Core learner journey (felt, not shown as a workflow):

```text
SEE → CHANGE POSITION → PREDICT → TEST → COMPARE
→ NOTICE RAY / SPATIAL RELATION → BUILD RELATION
→ APPLY TO NEW CONTEXT → RECOGNIZE EXAM REPRESENTATION
→ USE INDEPENDENTLY
```

Target deep structure:

```text
object position relative to F / 2F
        ↓
outgoing ray relation
        ↓
actual convergence / backward-extension intersection / no finite meeting
        ↓
image position
        ↓
image properties
```

Do **not** turn the experience into memorizing five imaging cases.

Experience grammar: **spatial / optical relation**. Do not copy Scene 02’s temporal/energy rhythm.

## S07-M01 — ENTER THE OPTICAL BENCH

**Stage:** ENTRY

**Learner enters with**

- may never have studied convex-lens imaging
- may not know F
- may not know 光屏
- may not know what “像” means
- should not be assumed to know real/virtual image

**Experience intention**

Create orientation and curiosity without teaching the imaging rule.

**Learner should feel**

“这里有一个我可以自己试的装置。”

**Physical world**

Show clearly: object, convex lens, screen, F / 2F positions. Vocabulary appears beside visible referents, only as needed.

**System says**

“这里有一个凸透镜实验。

先不用背规律。
我们会移动物体和光屏，看看会发生什么。”

Ground only when needed:

- F: “这个位置叫焦点 F。现在先认得它就可以。”
- 光屏: “这块白色板叫光屏。等会儿可以移动它找清楚的图样。”
- 像, when an image becomes relevant: “通过透镜看到的物体图样，物理里叫‘像’。”

**Learner does**

Looks at / enters the apparatus.

**System responds**

The bench is available to inspect. No rule, no exam, no reasoning prompt.

**Evidence meaning**

May support that the learner entered the phenomenon. Must not be interpreted as observation, description, or imaging understanding.

**Do not**

- teach five imaging cases
- define every optics term
- mention exam rules
- ask for reasoning
- specify React components

## S07-M02 — LOOK BEFORE EXPLAINING

**Stage:** OBSERVE

**Learner enters with**

- has seen the bench exists
- knows (or can now see) object, lens, screen
- does not yet have an imaging model

**Experience intention**

Make the learner inspect the physical world before answering questions about it.

**Learner should feel**

“我先看清楚这套装置，而不是先答题。”

**Physical world**

The bench is dominant. Learner may inspect / move object or screen where existing design permits. Visible consequence of that move is shown.

**System says**

“先看看这个装置。

物体、透镜和光屏分别在哪里？”

**Learner does**

Looks at the apparatus and identifies visible features. Records only what they actually saw.

**System responds**

Show the physical consequence of inspection/manipulation. Do not ask “为什么？” yet.

**Evidence meaning**

Supports observation interaction only. Does **not** prove understanding of imaging.

**Do not**

- ask why
- require five-case vocabulary
- leak evaluator language

## S07-M03 — SAY WHAT YOU ACTUALLY SEE

**Stage:** DESCRIBE

**Learner enters with**

- has looked at / moved the apparatus
- can point to object, lens, screen

**Experience intention**

Move from casual seeing to physical description without requiring textbook wording.

**Learner should feel**

“我在说我看见的，不是在默写定义。”

**Physical world**

The same bench remains visible and referable.

**System says**

“看着左边的实验。

用你自己的话说说，你现在看到了什么。”

If more specificity is actually required, ask a physical follow-up:

“物体、透镜和光屏之间是什么样的位置关系？”

**Learner does**

Describes the visible situation in their own language.

**System responds**

The description is kept. No grade, no “correct optics sentence.”

**Evidence meaning**

A meaningful observable relation may count. Exact textbook token presence must not be the evidence. Structured gates that already exist in Scene 07 evidence design remain authoritative; this Script must not invent a weaker evidence rule.

**Do not**

- say “不要只写‘变了’。”
- say “对着光具座分开说。”
- require imaging-case slogans

## S07-M04 — FIRST REAL PREDICTION

**Stage:** PREDICT

**Learner enters with**

- has seen the apparatus
- knows what F / screen refer to
- does **not** yet know the imaging model

**Experience intention**

Create a genuine prediction before experiment.

**Learner should feel**

“我先猜。猜错也没关系。等会儿真的试。”

**Physical world**

The bench is visible but the learner is not yet asked to complete the trial as the evidence of prediction. Prediction is precommit.

**System says**

“如果把物体移到 F 和 2F 之间，
你觉得会发生什么？”

Then:

“先猜就可以。
等会儿我们真的试一次。”

Then optionally:

“你现在想到理由了吗？”

Learner may say:

- “我有一个想法”
- “我就是先猜猜”
- “我现在还说不上来”

**Learner does**

Commits a prediction. May or may not give a reason.

**System responds**

The guess is remembered. The bench becomes the place to test it.

**Evidence meaning**

Prediction = precommit prediction. Optional reason = precommit reasoning only when the learner actually provides one. “No reason yet” must never be converted into reasoning evidence.

**Do not**

- treat prediction as an exam
- force fabricated causal reason
- reveal the imaging rule

## S07-M05 — TEST MY PREDICTION

**Stage:** EXPERIMENT (first trial)

**Learner enters with**

- a committed guess about F–2F
- no requirement to already know why

**Experience intention**

Experiment is not “complete four system steps.” It is: “I made a prediction. Now I can test it.”

**Learner should feel**

“我在检验刚才的猜想。”

**Physical world**

Physical world becomes dominant. Learner moves the object, then moves the screen, looking for the clearest image.

**System says**

“好，记住你刚才的猜想。

现在把物体移到 F 和 2F 之间。”

Then:

“现在移动光屏。

看看能不能找到最清楚的像。”

After meaningful observation:

“停在这里看看。

和你刚才猜的一样吗？”

Learner compares: 差不多一样 / 不太一样 / 我还不确定.

**Learner does**

Moves object, inspects with the screen, records what happened, compares with the guess.

**System responds**

The apparatus shows the result. No immediate imaging-table verdict.

**Evidence meaning**

May support experiment closure for this trial (prediction, intervention, observation, comparison, reflection) as already specified by Scene 07 evidence design. Must not be interpreted as MODEL or mastery. Comparison is not official correctness.

**Do not**

- immediately tell the rule
- make this feel like filling form 1 of 4
- skip the physical intervention

## S07-M06 — REPEAT WITH A PURPOSE

**Stage:** EXPERIMENT (later trials)

**Learner enters with**

- at least one observed case
- a new physical uncertainty, not “another table to fill”

**Experience intention**

Each later round answers a new physical question.

**Learner should feel**

“我在逐步找规律。” not “我还有第 3 张表要填。”

**Physical world**

Same bench. One new change per round. Existing Scene 07 trial set remains: F–2F, at F, inside F, partial cover. This Script does not invent extra experiments or delete required ones.

**System says** (examples; one per round)

“刚才在 F 和 2F 之间还能找到清楚的像。

如果继续把物体移近 F 呢？”

or:

“这次把物体放到 F。

再试一次——光屏还能找到清楚的像吗？”

or for u < f:

“现在把物体放到 F 里面。

看看这一次和前面哪里不一样。”

**Learner does**

Predicts (if the existing trial still requires precommit), changes the intended condition, inspects, compares.

**System responds**

Physical consequence of that new uncertainty. Still no five-case lecture.

**Evidence meaning**

Each closed trial is experiment evidence for that condition. Completing four rounds is not mastery and is not “the student memorized five cases.”

**Do not**

- number the experience as “第 3 张表”
- copy Scene 02’s two energy-intervention experiments here

## S07-M07 — SOMETHING IS CHANGING

**Stage:** EXPLAIN

**Learner enters with**

multiple observed cases.

**Experience intention**

Invite causal explanation only after there is evidence to explain.

**Learner should feel**

“我现在可以试着说为什么会不同。”

**Physical world**

The bench / recorded cases remain available as referents. Do not move ray construction into EXPLAIN (D064). EXPLAIN stays an account of already-seen results.

**System says**

“前几次实验里，物体的位置变了，
看到的结果也跟着变了。

你觉得真正起作用的是什么？”

If the learner struggles, they may refer to: where the object is; what the rays do; whether they actually meet; whether the screen can receive the image.

**Learner does**

Gives a causal / spatial account in their own words, with existing Scene 07 EXPLAIN structure still authoritative for evidence shape.

**System responds**

The explanation is kept. Scaffold within existing EXPLAIN AI policy. Do not reveal the final model.

**Evidence meaning**

May support L3-style fragment account of already-seen screen results, as Scene 07 evidence already specifies. Must not be treated as MODEL construction or L4.

**Do not**

- demand textbook wording as the only acceptable expression
- reveal the final model
- move ray construction into this moment

## S07-M08 — BUILD THE RELATION

**Stage:** MODEL

**Learner enters with**

several observations and an attempted explanation.

**Experience intention**

Turn several observations into ONE reusable relationship.

**Learner should feel**

“我不是在记四次实验。我是在找它们为什么不同。”

**Physical world / model workspace**

Support constructing:

```text
object position → ray relation → image consequence
```

The existing model-owned ray-construction UI remains the MODEL representation. This Script does not authorize copying Scene 02’s energy chain onto optics.

**System says** (conceptually)

“把刚才几次实验放在一起看。

物体放在哪里，
会先改变什么？

这个变化又会带来什么结果？”

**Learner does**

Constructs the causal/spatial chain using the model-owned representation.

**System responds**

Accepted or missing according to existing MODEL evaluator. Presentation must not infer acceptance.

**Evidence meaning**

MODEL evidence is the existing Scene 07 construction + authored bind. Structured UI completion alone is not model construction. Must not be treated as transfer or independent use.

**Do not**

- ask the learner to refill a seven-field internal tuple as the meaning of the task
- inspect later stages only to copy EXPLAIN widgets into MODEL

## S07-M09 — NEW OBJECT, SAME IDEA?

**Stage:** TRANSFER

**Learner enters with**

a constructed relation on the optical bench.

**Experience intention**

Recognize the model in a different physical context.

**Physical world**

Use the existing required transfer pair: projector, magnifying glass. Do not invent a new canonical transfer target.

**System says**

“光具座先放一边。

现在看这个投影仪。

你觉得刚才发现的关系还能不能用？”

Then present the physical situation. Ask for essential condition and a learner-authored causal link.

**Learner does**

Identifies the transferable relation in the new situation.

**System responds**

Existing target-bound deterministic evaluator remains authoritative. LLM semantic interpretation only where existing policy already allows (TRANSFER is not AI_OFF).

**Evidence meaning**

Existing L5 / transfer claims. Must not count as AI_OFF independent use. Do not ask the learner to refill all internal imaging fields.

**Do not**

- change the accepted TRANSFER semantic architecture
- treat “都有凸透镜” as sufficient if the existing evaluator already rejects surface-only answers

## S07-M10 — THIS IS WHAT AN EXAM DOES

**Stage:** EXAM

**Experience intention**

Reveal that an exam question is another representation of the same physical model.

**Learner should feel**

“原来考试只是把刚才那个关系换了一种问法。”

**Physical world**

Exam World, not the bench as the problem. Preserve: 题干 → what is happening physically → model recognition/reasoning → final answer.

**System says**

Present the existing Scene 07 exam design naturally. Do not turn the entire Scene into exam mode.

**Learner does**

Reads the stem, recognizes the situation, uses the relation, answers.

**System responds**

Existing exam evaluator.

**Evidence meaning**

Exam-pattern evidence only. Not mastery. Not AI_OFF.

**Do not**

- begin by asking for five-case recitation if the exam task is model recognition
- leak the official answer before commit

## S07-M11 — NOW YOU DO IT ALONE

**Stage:** AI_OFF

**Hard boundary:** NO LLM CALLS. No Tutor. No hidden hint. No prior hint leakage.

**Experience intention**

Remove learning scaffold and test independent model use.

**System says**

“最后换一个新的情况。

这一次没有提示。
按你自己的理解来判断。”

**Learner does**

Provides the required independent response on the existing canonical AI_OFF challenges.

**System responds**

If a deterministic semantic parser cannot understand natural language: return a neutral clarification request. **DO NOT call LLM.**

**Evidence meaning**

Only learner-authored / structured precommit evidence and legitimate deterministic/system-derived interpretation. L6 must remain truthful.

**Do not**

- authorize LLM use because interpretation is hard
- hide a known AI_OFF hard-boundary defect if it still exists in runtime
- treat this Script as permission to finish an unrelated AI_OFF architecture repair

## S07-M12 — LOOK BACK

**Stage:** COMPLETE

**Experience intention**

Show the learner what changed in their thinking.

**Learner should feel**

“我刚才是这样走过来的。” not “完成！已经掌握了。”

**System says** (concise cognitive trace)

“一开始你先猜了……
实验以后你发现……
后来你用这个关系解释了……
最后你在新情境里自己用了它。”

**Learner does**

Looks back. No new physics task.

**System responds**

Trace of what they actually did. No mastery claim.

**Evidence meaning**

COMPLETE is not additional L-level evidence. Do not claim mastery beyond evidence.

**Do not**

- display “已经掌握凸透镜成像”
- invent outcomes the learner did not produce
